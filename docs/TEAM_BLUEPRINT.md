## 제품 한눈에

> 우리팀이 운영하는 매장 단말 3종.

| 제품 | 무엇 | 핵심 기능 |
|-----|-----|--------|
| **키오스크** (kiosk_v4) | 매장 고객용 셀프 주문·결제 단말 (Android 태블릿 / Windows) | 상품 탐색 → 장바구니·옵션 → 결제(카드 VAN · 간편결제 QR) → 쿠폰·스탬프 적립 → 영수증·주문번호 출력 |
| **주문에이전트** (appfit_order_agent) | 매장 주문 접수·주방(KDS) 단말, 900+ 매장 (Android / Windows) | 실시간 주문 수신(WebSocket) → 자동 접수 → 라벨·영수증 자동 출력 → 상태 관리(신규·준비중·준비완료·픽업완료) |
| **DID** (did) | 매장 대형 디스플레이 (Android 셋톱박스 / Windows) | 사이니지(이미지·동영상 콘텐츠 재생) ↔ 주문번호 호출 화면 토글, 준비완료 번호 실시간 표시 |

## 1. 팀 미션

매장 고객 접점 단말(키오스크 · 주문에이전트 · DID 등) 프로젝트를 다양한 하드웨어 환경을 고려하여 안정적으로 운영하며 프로젝트 설계에 신규 브랜드 확장을 최소한의 공수로 빠르고 일관되게 지원되도록 반영한다. 
관련 신사업을 원활하게 지원한다.
