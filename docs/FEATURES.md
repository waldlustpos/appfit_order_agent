
# 주문접수에이전트 개요
별도 기획, 디자인 없이 매머드커피 초기 버전을 토대로 운영 경험 및 매머드커피 및 타 브랜드 요구사항들을 종합적으로 반영하며 진행되어온 프로젝트.



# Kokonut → Appfit 전환 주요 변화점 요약
- UI 개선
- 크로스플랫폼 — Android · Windows 동시 지원
- KDS모드 기본 기능화 (Appfit의 주문상태 변경시 알림처리 시스템을 활용)
- 다국어 처리 (한국어, 일본어, 영어)
- 회폐단위처리 (원화, 엔화)
- 외부프린터 지원
- 라벨프린터 지원
- UI 브랜드 테마 지원


## 상세기능

### 1. Flutter 기반

| 항목 | 내용 |
|------|------|
| 프레임워크 | Flutter |
| 특징 | 하나의 코드로 여러 운영체제 앱을 동시에 개발 |

### 2. 크로스플랫폼 — Android · Windows 동시 지원

같은 앱을 안드로이드 단말과 윈도우 PC에서 모두 사용.

| 플랫폼 | 주요 단말 | 비고 |
|------|------|------|
| Android | Sunmi D3 MINI, D2s_KDS, 안드로이드 태블릿 등 | — |
| Windows | 윈도우 POS | 32비트 지원불가 |

### 3. 메인 모드 (주문 접수)

주 용도: 카운터에 배치. 주문접수 / 주문상태변경 / 상품관리.

**주문을 직접접수를 하는 단말이 매장에 유일한지 운영시 반드시 확인 필요.** 

| 영역 | 설명 |
|------|------|
| 좌측 탭 | 주문현황 / 주문내역 / 상품관리 / 멤버십 |
| 상단 표시 | 시간, 네트워크 상태, 로그아웃 버튼 |
| 주문현황 탭 | 신규 / 준비중 / 준비완료 / 완료 4단계를 위→아래로 동시 노출 |
| 카드 형태 | 작은 정사각형 카드를 가로로 나열 |
| 상세 보기 | 카드를 누르면 주문 상세 팝업 |

### 4. KDS 모드 (주방 디스플레이)

주 용도: 주방에서 보는 큰 카드 디스플레이. 카드 안에 메뉴와 옵션이 크게 보이고 좌우로 스크롤.

| 영역 | 설명 |
|------|------|
| 상단 탭 | 전체 / 진행 / 픽업 / 완료 / 취소 + 정렬·일괄완료 버튼 |
| 카드 배치 | 한 카드씩 크게, 좌우로 스크롤 |
| 카드 구성 | 주문번호·항목 수·접수 시각 / 메뉴 리스트 / 상태 전환 버튼 / 메모 |


- KDS 모드 단독으로도 사용 가능. **KDS 모드에서 주문 직접 수신은 별도 토글로 ON**.




### 5. 프린터

매장 환경에 맞춰 내장·외부·라벨 프린터를 각각 켜고 끌 수 있음. 내장·외부프린터 주문서/영수증 각각 출력 여부 지정 가능. (출력방향 설정) 

| 구분 | 용도 | 비고 |
|------|------|------|
| 내장 영수증 | Sunmi 내장프린터 지원 디바이스 전용 | D3MINI, T2_mini_s |
| 외부 영수증 | USB 연결한 별도 영수증 프린터 | — |
| 라벨 | 컵에 붙이는 라벨스티커 | 현재 5×7cm 용지, REXOD RXLA-561 모델만 지원 |


### 6. 상품관리

| 항목 | 설명 |
|------|------|
| 기능 | 판매 상품을 **판매중 / 품절 / 숨김** 중 하나로 전환 |
| 부가 기능 | 카테고리 분류 보기, 상품명 검색 |
| 메인 모드 진입 | 좌측 사이드바 **상품관리 탭** |
| KDS 모드 진입 | 왼쪽 **Drawer 메뉴(햄버거 버튼) → 상품관리** |

### 7. 멤버십 (메인 모드 전용)

| 항목 | 설명 |
|------|------|
| 기능 | 전화번호·바코드로 회원 조회, 스탬프 적립·취소, 쿠폰 사용·취소, 보유 쿠폰 확인 |
| 진입 | 좌측 사이드바 **멤버십 탭** |
| 모드 제약 | **메인 모드 전용** — KDS 모드에서는 진입점 없음 |
| 바코드스캔 | Sunmi내장 스캐너 · 외부스캐너 · 토스프론트/네이버커넥트 스캐너 |
