1부무엇이 달라졌나

주문 에이전트가 kokonut 플랫폼에서 AppFit 플랫폼으로 옮겨 갔습니다. 주문을 받고 만들고 내보내는 매장의 일 자체는 그대로지만, 화면과 설정이 넓어졌고 매장 ID와 로그인 방식이 바뀌었습니다. 이 1부만 읽어도 전환 시 필요한 준비는 끝납니다.

1.1한눈에 보는 변화

기기 Windows POS 지원 안드로이드 단말뿐 아니라 매장 윈도우 POS에서도 같은 앱을 그대로 씁니다.
언어 3개 국어 한국어 · English · 日本語. 설정에서 언제든 바꿀 수 있습니다.
금액 원 · 엔 표시 매장이 있는 나라에 맞춰 원(₩) 또는 엔(¥)으로 금액을 표시합니다.
주방 주방 모니터 기본 탑재 별도 연동 설정 없이 주방 모니터(KDS) 모드로 바로 전환됩니다. 주문 상태가 실시간으로 맞춰집니다.
출력 프린터 설정 세분화 기존 내장프린터에 더해 외부프린터도 지원하며, 각 프린터별로 영수증 · 주문서 출력 방향을 설정할 수 있습니다. '기기 호출 알림'으로 키오스크 용지 부족 등의 알림도 출력할 수 있습니다.
라벨 라벨프린터 지원 매장에서 라벨프린터를 사용 가능합니다. 단순 메뉴정보 또는 QR코드를 추가 인쇄하여 활용할 수 있습니다.

1.3새로 설치할 때 확인할 사항

AppFit 주문 에이전트는 기존 kokonut 앱과는 별개의 새 앱으로 설치됩니다. 기존 앱을 지우고 새로 설치하는 방식이라, 로그인 정보를 포함한 모든 설정값이 초기화된 상태로 시작합니다.

매장 ID를 모르는 경우

기존 kokonut 매장 ID(K로 시작)는 AppFit 매장 ID로 그대로 쓸 수 없습니다. 새 매장 ID를 안내받지 못했다면 로그인하지 말고 브랜드 담당자 또는 고객센터(3.5)로 문의해 주세요.

2부화면별 사용 안내

앱은 주문접수 모드(카운터)와 주방모니터 모드(주방) 두 가지로 씁니다. 2.1~2.6은 주문접수 모드, 2.7은 주방모니터 모드, 2.8은 두 모드 공통 설정입니다.

2.1로그인

항목설명

아이디 저장다음 실행 때 매장 ID가 미리 채워집니다.

모드 선택주문접수 / 주방모니터 중 이 기기의 역할을 고릅니다. 로그인 후에도 설정에서 바꿀 수 있습니다.

안드로이드에서 "다른 앱 위에 표시" 권한을 물어보는 경우 — 앱을 최소화한 상태에서 화면 위에 작은 아이콘을 띄우기 위한 권한입니다. 설정하기를 눌러 허용해 두면 최소화 후에도 주문 알림을 놓치지 않습니다.

자동 접수

설정 → 일반 설정 → 픽업 오더 자동 접수를 켜면 주문이 들어오는 즉시 신규주문 → 주문접수로 자동 처리되고 주문서도 바로 출력됩니다. 바쁜 매장에서 주로 씁니다.

중요

자동 접수를 켠 기기는 매장에 하나여야 합니다. 자세한 내용은 3.1을 꼭 확인하세요.

일괄 완료

상품준비완료 단계 제목 옆의 건수 배지를 누르면 그 단계의 주문을 한 번에 완료 처리합니다. 마감 정리에 편리합니다. (연속 오작동 방지를 위해 누른 뒤 몇 초간 다시 눌리지 않습니다.)

주문 취소

  1. 주문 취소를 누릅니다.
  2. 취소 사유를 고릅니다 — 매장 사정 / 매장 마감·휴무 / 고객 요청 / 품절 / 재료 소진 / 시스템 오류 / 기타
  3. 확인 창에서 한 번 더 확인하면 취소됩니다.

키오스크에서 들어온 주문은 이 앱에서 취소할 수 없습니다. "키오스크 주문은 키오스크 기기에서 취소해주세요"라는 안내가 뜹니다. 키오스크 기기에서 처리해 주세요.

재출력

주문서나 라벨이 제대로 나오지 않았을 때, 주문 상세 창에서 영수증 재출력 · 라벨 재출력으로 다시 뽑을 수 있습니다. 완료 · 취소된 주문에서도 가능합니다.

2.4주문내역

  • 날짜 선택 — 달력에서 원하는 날짜의 주문을 조회합니다. 오늘날짜조회로 오늘로 바로 돌아옵니다.
  • 필터 — 전체주문 / 픽업완료 / 주문취소
  • 정렬 — 오래된 순 ↔ 최신 순 전환
  • 건수 표시 — 총 n건, 취소 n건이 함께 보입니다.
  • 목록의 주문을 누르면 상세 창이 열리고, 여기서도 재출력과 주문 취소가 가능합니다.

2.5상품관리

상태손님에게 보이는 모습
판매중정상적으로 주문할 수 있습니다.
품절메뉴에는 보이지만 주문할 수 없습니다. 재료가 떨어졌을 때 사용합니다.
  • 카테고리 · 품절 필터와 상품명 검색으로 원하는 상품을 빠르게 찾습니다.
  • 진입 경로 — 주문접수 모드는 왼쪽 상품관리 탭, 주방모니터 모드는 메뉴 버튼(≡) → 상품관리

2.6멤버십

  • 회원 조회 — 전화번호 입력 또는 바코드 스캔
  • 스탬프 — 적립 및 적립 취소
  • 쿠폰 — 사용 및 사용 취소, 보유 쿠폰 확인
  • 바코드 스캐너 — 기기 내장 스캐너, 외부 USB 스캐너를 지원합니다. 토스 프론트 · 네이버 커넥트 스캐너는 Windows 장비에서만 지원합니다.

멤버십은 주문접수 모드 전용입니다. 주방모니터 모드에는 멤버십 탭이 없습니다.

2.7주방 모니터(KDS)

주방에 두고 쓰는 큰 카드 화면입니다. 메뉴와 옵션이 크게 보여 조리 중에도 읽기 쉽습니다.

요소설명
상단 탭 5개전체 · 진행 · 픽업 · 완료 · 취소. 탭마다 현재 건수가 함께 표시됩니다.
주문 카드주문번호, 총 항목 수, 주문 시각, 메뉴 목록, 손님 메모가 크게 보입니다.
카드 버튼진행 탭에서는 픽업 요청, 픽업 탭에서는 주문 완료. 주문 상세로 자세히 볼 수 있습니다.
일괄 완료픽업 탭에서만 나타납니다. 픽업 대기 주문을 한 번에 완료 처리합니다.
정렬오래된 주문순 / 최신 주문순. 탭마다 따로 기억됩니다.
날짜 조회전체 탭에서만 달력으로 지난 날짜를 조회할 수 있습니다.
좌우 스크롤카드가 많으면 화면 양옆의 화살표 버튼으로 넘깁니다. 새 주문이 오면 자동으로 맨 앞으로 이동합니다.
주방 모니터만으로 매장을 운영하려면

기본적으로 주방 모니터는 주문을 직접 받지 않고 보기만 합니다. 카운터 접수 기기 없이 주방 모니터 하나로 운영하려면 설정 → 모드 설정 → 주문 접수를 켜야 합니다. 이 토글을 켜야 상단에 오더 영업 토글도 나타납니다.

주의 — 주방 모니터의 주문 접수를 켰다면, 카운터의 자동 접수는 반드시 꺼야 합니다. (3.1 참고)

3.1접수 단말 중복 주의

한 매장에서 주문을 자동으로 접수하는 기기는 하나여야 합니다

여러 기기가 동시에 자동 접수를 하면 같은 주문이 중복 처리되거나 주문서 · 라벨이 두 번 인쇄될 수 있습니다. 기기를 추가하거나 주방 모니터를 새로 들일 때 반드시 확인하세요.

표 3-1. 자동 접수와 관련된 설정 3가지
설정위치중복 주의
픽업 오더 자동 접수 주문접수 모드 → 설정 → 일반 설정 예 — 아래 항목과 동시에 켜지 않도록 확인
주문 접수 (주방모니터) 주방모니터 모드 → 설정 → 모드 설정 예 — 위 항목과 동시에 켜지 않도록 확인
키오스크 주문 자동 접수 설정 → 키오스크 설정 아니오 — 키오스크 주문에만 적용되므로 위 두 항목과 무관합니다.

권장 구성

  • 카운터 + 주방 — 카운터 기기에서만 자동 접수를 켜고, 주방 모니터의 '주문 접수'는 끕니다.
  • 주방 모니터 단독 — 주방 모니터의 '주문 접수'를 켜고, 다른 접수 프로그램은 사용하지 않습니다.

3.3앱 업데이트 방식

매장 기기에 따라 업데이트가 오는 경로가 다릅니다.

대상업데이트 경로점주가 할 일
매머드커피 + Sunmi 단말 Sunmi 앱스토어 앱스토어를 통해 배포됩니다. 앱 안에서는 업데이트를 확인하지 않습니다.
그 외 모든 매장 · 기기
(Windows POS 포함)		 앱 내 자동 업데이트 앱을 켤 때 자동으로 확인합니다. 업데이트 안내가 뜨면 진행하고, 완료되면 앱이 다시 시작됩니다.

업데이트는 영업 시작 전에 하는 것을 권장합니다. 업데이트 중에는 앱이 재시작되므로 주문을 받을 수 없습니다. 현재 버전은 메뉴 버튼(≡) 하단 또는 설정 → 업데이트에서 확인할 수 있습니다.

3.4영업 시작과 종료

상황동작
영업 시작앱 실행 후 상단 오더 토글을 영업중으로 바꿉니다. 이때부터 손님이 주문할 수 있습니다.
잠시 주문 중단오더 토글을 준비중으로 바꿉니다. 재료 소진이나 혼잡 시 사용합니다.
영업 종료앱을 종료하거나 로그아웃하면 자동으로 '오더 준비중'으로 바뀝니다.
가장 흔한 문의

"주문이 안 들어와요"의 상당수는 오더 토글이 준비중인 경우입니다. 주문이 없다고 느껴지면 이것부터 확인해 주세요.
