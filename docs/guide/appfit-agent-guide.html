1부무엇이 달라졌나

주문 에이전트가 kokonut 플랫폼에서 AppFit 플랫폼으로 옮겨 갔습니다. 주문을 받고 만들고 내보내는 매장의 일 자체는 그대로지만, 화면과 설정이 넓어졌고 매장 ID와 로그인 방식이 바뀌었습니다. 이 1부만 읽어도 전환 시 필요한 준비는 끝납니다.

1.1한눈에 보는 변화

기기 Windows POS 지원 발트포스 도입 시 안드로이드 단말뿐 아니라 매장 윈도우 POS에서도 같은 앱을 그대로 씁니다.
주방 주방 모니터 기본 탑재 별도 연동 설정 없이 주방 모니터(KDS) 모드로 바로 전환됩니다. 주문 상태가 실시간으로 맞춰집니다.
출력 프린터 설정 세분화 기존 내장프린터에 더해 외부프린터도 지원하며, 각 프린터별로 영수증 · 주문서 출력 방향을 설정할 수 있습니다. '기기 호출 알림'으로 키오스크 용지 부족 등의 알림도 출력할 수 있습니다.

1.2새로 설치할 때 확인할 사항

AppFit 주문 에이전트는 기존 kokonut 앱과는 별개의 새 앱으로 설치됩니다. 기존 kokonut 앱을 지우지 않고 설치하므로, AppFit 전환 전까지는 두 앱이 함께 설치된 상태로 있습니다. 전환 이전까지는 기존 kokonut 앱으로 계속 주문을 받고, 8월 31일 전환 이후에는 kokonut 앱을 사용하지 않으므로 삭제해도 무방합니다. AppFit 주문 에이전트는 새 앱이므로 로그인 정보를 포함한 모든 설정값이 초기화된 상태로 시작합니다.

매장 ID를 모르는 경우

기존 kokonut 매장 ID(K로 시작)는 AppFit 매장 ID로 그대로 쓸 수 없습니다. 새 매장 ID를 안내받지 못했다면 로그인하지 말고 브랜드 담당자 또는 고객센터로 문의해 주세요.

2부화면별 사용 안내

앱은 주문접수 모드(카운터)와 주방모니터 모드(주방) 두 가지로 씁니다. 평소에는 주문접수 모드로 쓰고, 주방모니터 모드는 주방에 별도 화면을 둘 때 필요시 전환해서 사용합니다. 주방모니터 모드는 기기를 두 대 이상 두고 그중 한 대를 주방에 별도로 비치하는 매장에서 주로 운영합니다.

윈도우 POS는 예외입니다. 새로 설치한 윈도우 POS는 '키오스크 주문 주문서 및 알림소리'가 처음부터 ON으로 시작합니다(노출은 동일하게 OFF). 키오스크 주문의 주문서와 알림음을 POS가 받아야 하기 때문입니다. 이미 사용 중인 윈도우 POS의 설정값은 그대로 유지되므로, 필요하면 설정에서 직접 켜 주세요.

3부도입 · 운영 확인사항

매장에 설치하거나 기기를 늘릴 때 확인해야 할 것들입니다.

3.1접수 단말 중복 주의

한 매장에서 주문을 자동으로 접수하는 기기는 하나여야 합니다

여러 기기가 동시에 자동 접수를 하면 같은 주문이 중복 처리되거나 주문서 · 라벨이 두 번 인쇄될 수 있습니다. 기기를 추가하거나 주방 모니터를 새로 들일 때 반드시 확인하세요.

설정위치중복 주의
픽업 오더 자동 접수 주문접수 모드 → 설정 → 일반 설정 예 — 아래 항목과 동시에 켜지 않도록 확인
주문 접수 (주방모니터) 주방모니터 모드 → 설정 → 모드 설정 예 — 위 항목과 동시에 켜지 않도록 확인
키오스크 주문 자동 접수 설정 → 키오스크 설정 아니오 — 키오스크 주문에만 적용되므로 위 두 항목과 무관합니다.

권장 구성

  • 카운터 + 주방 — 카운터 기기에서만 자동 접수를 켜고, 주방 모니터의 '주문 접수'는 끕니다.
  • 주방 모니터 단독 — 주방 모니터의 '주문 접수'를 켜고, 다른 접수 프로그램은 사용하지 않습니다.

3.2영업 시작과 종료

상황동작
영업 시작앱 실행 후 상단 오더 토글을 영업중으로 바꿉니다. 이때부터 손님이 주문할 수 있습니다.
잠시 주문 중단오더 토글을 준비중으로 바꿉니다. 재료 소진이나 혼잡 시 사용합니다.
영업 종료앱을 종료하거나 로그아웃하면 자동으로 '오더 준비중'으로 바뀝니다.
