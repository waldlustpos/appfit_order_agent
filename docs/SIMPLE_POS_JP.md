- **§2** AppFit Core API 실사 — `POST /v1/orders`(`orderSource=WALD_POS`) · 취소 · 카탈로그 · 증분 동기화
- **§6** Square 일본 결제 연동 (Terminal API 권고, `kiosk_v3_japan` 실측)
- **§7** 일본 법규·세무 — **2027-04 소비세 개정이 최우선 변수. 세율 하드코딩 금지**
- **§8** POS 고유 기술 설계 영역 — 오프라인 완결 판매 · 로컬 원장 · 영업일 마감 · 현금 관리 ·
  금액 계산 결정론 · 크래시 원자성. 사내 12개 레포 전수 확인 결과 **선례가 없는 신규 설계**
- **§9** UI/UX — Simple 6원칙 · 1280×800 레이아웃 · 취식/포장 3중 표시 · **이 앱 디자인 토큰의 재사용 판정표**
- **§12** 정정 이력 (2차 재검증에서 서술 5건 정정 + 신규 발견 35건)

## 이 앱에도 해당하는 발견 하나

**번들 Pretendard 에 일본어 한자가 없어 ja 문자열 85%가 폰트 혼합 렌더링**이라는 실측(§9.7).
`appfit_simple_pos` 는 `fontFamilyFallback` 지정으로 해결했으나, **이 앱은 아직 그 상태다.**
일본 매장에 ja 로케일을 내보낼 때 함께 처리해야 한다.
