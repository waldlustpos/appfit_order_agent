라벨 출력 오케스트레이션의 단일 진입점. 주문 1건을 LabelPrintData.fromOrder()로 메뉴 qty 만큼 N장 펼친 뒤, 장별로 이미지 생성 → 인쇄 → 1.5초 후 1회 재시도를 조율한다. 재시도 후에도 실패한 장은 인덱스 단위로 집계해 Sentry 로 보고(운영자 [라벨 재출력]로 복구). 주문 단위 in-flight dedup 은 상류 OutputQueueService의 _inFlight* Set 이 담당.
