외부 프린터 출력 글로벌 직렬 큐(싱글턴). 점유 충돌(BUSY) / 일시 단선(NO_DEVICE) / transport 오류를 지수 backoff 0/2/5/10/20/40/60s(누적 ~137s · 7회 시도)로 흡수. 인메모리 단일 큐 — 앱 재시작 시 미완료 잡은 분실. 단일 worker가 잡 사이 직렬화를 보장하므로 호출 측이 동시에 enqueue 해도 안전.

enqueue()(PrinterJob job) → Future<bool>진입점
동작
잡을 큐 끝에 추가하고 worker가 idle이면 _kick()으로 깨움. 반환 Future는 success 시 true, maxAttempts 실패/transport 미주입 시 false — 호출자가 최종 결과 await 가능
로그
[PrinterQueue] enqueue id= kind= job= qsize= (PLATFORM 태그)
P
_kick() / _runLoop()→ void / Future<void>단일 worker
직렬 보장
_running이면 return, 아니면 scheduleMicrotask(_runLoop). _runLoop는 while(_queue.isNotEmpty)로 removeAt(0) → _processJob 순차 처리 — 한 잡이 backoff 중이면 후속 잡 적체(cap 60s를 둔 이유)
P
_processJob()(PrinterJob job) → Future<void>backoff 루프
가드
transport null이면 PrinterNoDevice('transport not initialized')로 즉시 final — onFinalFailure 호출 + complete(false)
흐름
for (i = 0; i < maxAttempts; i++)→ i>0이면 _backoffs[i] 대기→ transport.send(bytes, jobName)→ PrinterSuccess → complete(true)
예외
transport.send가 throw하면 PrinterTransportError('transport.send threw: …')로 감싸 재시도 대상에 포함. 전 회차 실패 시 onFinalFailure?.call(job, lastResult) 1회 + complete(false), 다음 잡 처리는 계속
