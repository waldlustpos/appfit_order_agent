---
description: i18n JSON 변경분에 l10n-auditor로 키 누락 점검 후 strings.g.dart 재생성
---

아래 순서로 실행한다:

1. Bash 툴로 변경된 i18n 파일 확인:
   ```
   git diff --name-only lib/i18n/
   ```
   변경 사항이 없으면 "i18n 변경 없음" 으로 종료한다.

2. **l10n-auditor 서브에이전트를 호출**하여 ko/en/ja 키 누락·중복·미사용을 감사한다. 누락이 발견되면 결과를 사용자에게 먼저 보고하고 진행 여부를 묻는다.

3. 사용자가 진행에 동의하거나 누락이 없으면 코드 재생성:
   ```
   dart run build_runner build --delete-conflicting-outputs
   ```

4. 생성된 `lib/i18n/strings.g.dart` 변경 라인 수를 요약하고 완료를 알린다.
